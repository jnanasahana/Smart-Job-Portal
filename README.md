Smart Job Portal

Project Overview

Smart Job Portal is a web-based application developed using Python and Flask to simplify the job searching and recruitment process. It provides a platform where job seekers can explore available job opportunities and manage their job applications. The application uses MongoDB to store and manage project data.

Problem Statement

Finding suitable job opportunities and managing recruitment activities can be time-consuming. Job seekers often need to visit multiple platforms to search for jobs. Smart Job Portal aims to simplify this process by providing a centralised platform for job searching and recruitment management.

Technologies Used

- **Programming Language:** Python
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Flask
- **Database:** MongoDB
- **Development Tool:** Visual Studio Code
- **Version Control:** Git and GitHub

Key Features

1. User registration and login.

Installation Instructions

Prerequisites

- Python installed on your system.
- MongoDB database.
- Visual Studio Code (recommended).

Steps to Run the Project

1. Clone the repository:

   bash
   git clone https://github.com/jnanasahana/Smart-Job-Portal.git

2. Navigate to the project directory:

   bash
   cd Smart-Job-Portal

3. Create a virtual environment:

   bash
   python -m venv venv

4. Activate the virtual environment:

   **Windows:**
   bash
   venv\Scripts\activate

5. Install the required dependencies:

   bash
   pip install -r requirements.txt

   If a requirements.txt file is not available, install the actual dependencies used by your project.

6. Configure the MongoDB connection and required environment variables.

7. Run the Flask application using its actual entry-point file:

   bash
   python app.py

8. Open the application in your browser using the local URL displayed by Flask.
